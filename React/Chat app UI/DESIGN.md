# Relay Design System & Architecture Specification

## Color Tokens
- **Canvas Primary:** `#FFFFFF` (Light) / `#090A0D` (Dark)
- **Surface Secondary:** `#F8FAFC` (Light) / `#111318` (Dark)
- **Surface Tertiary:** `#F1F5F9` (Light) / `#161920` (Dark)
- **Surface Elevated:** `#FFFFFF` (Light) / `#1B1E26` (Dark)
- **Hairline Borders:** `#E2E8F0` (Light) / `#222631` (Dark)
- **Text Primary:** `#0F172A` (Light) / `#F8FAFC` (Dark)
- **Text Muted:** `#64748B` (Light) / `#94A3B8` (Dark)
- **Brand Primary:** `#2563EB` (Light) / `#3B82F6` (Dark)
- **Outbound Bubble Fill:** `linear-gradient(135deg, #2563EB 0%, #4F46E5 100%)`
- **Inbound Bubble Fill:** `#F1F5F9` (Light) / `#181B23` (Dark, `1px solid #252A36`)
- **Thread Branch Accent:** `#8B5CF6` (`rgba(139, 92, 246, 0.12)` soft fill)
- **Presence Dots:** Online `#10B981`, Idle `#F59E0B`, DND `#F43F5E`, Offline `#64748B`
- **Delivery Ticks:** Sent/Delivered `#94A3B8`, Read `#38BDF8`

## Typography
- **UI Chrome & Message Body:** `Inter` (`13px–14.5px`, `1.55` line height, max measure `62ch`)
- **Tabular Meta & Timestamps:** `JetBrains Mono` / `tabular-nums` (`11px–12px`)
