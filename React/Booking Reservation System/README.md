# AURA Concierge — Modern Human-Centric Booking & Reservation System

A spatial, tactile, and hospitality-first booking engine built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS**. Designed following the **Stitch.md** design system specification ("Tactile Architectural Concierge & Warm Limestone").

---

## 🌟 Key Architectural Capabilities

### 1. Interactive Spatial Floorplan & Vibe Zone Picker
- **Clickable Architectural SVG Map & Zone Explorer:** Direct seat-by-seat inspection of individual tables, reformer machines, and creative studios.
- **Sensory & Acoustic Vibe Pills:** Tagged context (`[🕯️ Intimate & Low-Noise]`, `[🥂 High-Energy Social]`, `[☀️ Natural Daylight]`, `[🔌 Power Outlet Nearby]`, `[🐾 Dog-Friendly Patio]`).
- **1-Click Vertical Archetype Switcher (Top Demo Ribbon):**
  - `🍽️ Fine Dining & Chef's Table` (*The Luminary Osteria*: Solarium booths, wood-fired hearth, heated olive courtyard, acoustic wine vault).
  - `🧖‍♀️ Boutique Wellness & Reformer Studio` (*Sanctuary Reformer*: Front-row mirrors, ambient lumens, private infrared suites).
  - `🏛️ Creative Studio & Padel Court Booking` (*Atelier 9 & Baseline Club*: Panoramic glass courts, infinite cyclorama, acoustic podcast suite).

### 2. Anti-Dead-End Time Scrubber & "Sweet-Spot" Availability Radar
- **24-Hour Availability & Energy Wave:** Ambient crowd curve (`Calm Morning` → `Brisk Lunch` → `Golden Hour 5:45 PM` → `Prime Evening Buzz`) with live decibel readings and natural light markers.
- **Smart "Shift 15 Mins" Nudges:** Automatically catches sold-out slots (e.g. 7:00 PM) and unfolds micro-pivots in context (*"Shift 15m earlier to 6:45 PM for a Window Booth, or grab 7:15 PM at the Chef's Counter"*).
- **Intent & Duration Pacer:** Toggle between `[⚡ 45-Min Express]`, `[🍷 90-Min Classic]`, and `[✨ 2.5-Hour Celebration]`—dynamically unlocking interstitial **Tetris gap windows** without cannibalizing prime seatings.

### 3. Conversational Soft Hold, Group Poll & Concierge Checkout
- **15-Minute "Text the Group" Soft Hold & Live Poll:** Locks table inventory with a monospace countdown timer (`14:59 LEFT`) and generates a shareable invite link with simulated real-time friend responses (`"👍 I'm In"` + dietary notes).
- **"Make It Effortless" Hospitality Micro-Prompts:** 1-tap brief pills (`🎂 Subtle Birthday`, `💼 Client Dinner`, `👶 Stroller Space`, `🥜 Severe Allergy Protocol`, `♿ Step-Free Access`).
- **Instant 3D Perforated Digital Pass:** Flips into a botanical charcoal velvet digital ticket with scannable QR code, exact table pin, 1-click `.ics` Calendar sync, and Day-Of companion controls.

### 4. High-Impact Feature Matrix
- **Daylight & Evening Seat Preview:** Time slider smoothly shifts the room from sunlit brunch to candlelit dinner with radial table lamp glows and solar angle calculations.
- **The "No-Penalty Swap" Marketplace:** Atomic two-party transfer allowing guests to trade peak slots with waitlisters and waive late cancellation fees.
- **Split-Deposit & Group Tab Pre-Auth:** Transparent per-person deposit ledger (`$25/guest` or `$12.50/share`).
- **Weather-Safe Patio Contingency:** Outdoor tables linked to an automatic indoor shadow table (`100% Dry Guarantee`).
- **Toggleable Host Stand & Pacing Waterfall Lens:** Operator mode displaying 15-minute kitchen arrival throttles (`16 guests max / bucket`), live turn progress, and VIP guest dossiers.

## 🚀 Running the Project

```bash
cd "Booking Reservation System"
npm install
npm run dev
```

Visit `http://localhost:5173` in your browser.

To produce an optimized production build:
```bash
npm run build
npm run preview
```
